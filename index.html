받자마자(FirstCheck) 개인정보처리방침

시행일 및 최종 수정일: 2026년 8월 27일

요약: 받자마자(FirstCheck)는 회원가입, 개발자 자체 사용 분석 및 자체 서버를 운영하지 않습니다. 사용자가 입력하거나 선택한 정보와 앱에서 만든 파일은 기기 안에서 처리되며 개발자 서버로 전송되지 않습니다. OCR 대상 이미지와 인식된 문자도 원격 OCR 서버로 전송되지 않습니다. 다만 Google ML Kit는 진단 및 사용 분석을 위한 제한적인 기기·앱·성능 메타데이터를 수집하며, Google AdMob은 광고 제공을 위해 일부 데이터를 수집·공유합니다. 각 SDK의 처리 내용은 아래 3항에서 구분하여 설명합니다.

1. 적용 범위

이 개인정보처리방침은 패키지명 com.leehy9307.firstcheck으로 제공되는 Android 앱 “받자마자(FirstCheck)”에 적용됩니다.

받자마자는 새로 받은 제품의 초기 검사, 반품 일정, 영수증 문자 인식과 사진·영상·음성 증빙을 사용자의 기기 안에서 정리하도록 돕습니다.

2. 앱이 기기 안에서 처리하는 정보

사용자가 앱 기능을 이용하면 다음 정보가 기기 안에서 처리되거나 저장될 수 있습니다.

  • 사용자가 입력한 제품명, 구매처, 구매일·수령일, 반품 마감일, 주문 정보와 메모
  • 사용자가 선택한 영수증 또는 주문 화면과 기기 내 OCR로 인식한 문자
  • 검수 항목, 진행 상태 및 통과·확인 필요·즉시 중단·해당 없음 결과
  • Android 시스템 선택기에서 사용자가 직접 고른 사진·영상의 URI 접근 정보와 해당 증빙
  • 사용자가 녹음 기능을 실행하여 만든 음성 파일
  • 반품 마감 알림을 위한 날짜와 로컬 예약 정보
  • 앱 내부 JSON 기록과 사용자가 생성한 PDF

위 정보는 앱의 기능을 제공하기 위해 사용자의 기기에서만 처리됩니다. 받자마자는 자체 서버나 개발자 계정으로 이 정보를 전송하지 않으며, OCR 대상 이미지와 인식된 문자도 원격 OCR 서버로 전송하지 않습니다. 아래 3항에서 설명하는 배너 광고 구성요소 역시 이 정보에 접근하지 않습니다. 다만 Google ML Kit는 OCR 내용이 아닌 제한적인 진단·사용 분석 메타데이터를 Google에 전송할 수 있습니다.

3. 개인정보의 수집, 전송 및 공유

  • 개발자에 의한 수집: 없음
  • 앱 검수 기록의 기기 밖 전송: 없음
  • 개발자 자체 사용 분석 또는 추적: 없음
  • 개발자에 의한 제3자 판매: 없음
  • 외부 SDK에 의한 처리: Google AdMob·User Messaging Platform 및 Google ML Kit가 아래와 같이 서로 다른 데이터를 처리합니다.

3-1. 배너 광고

받자마자는 앱을 무료로 유지하기 위한 운영 비용 목적으로 화면 아래에 배너 광고 1개를 표시합니다. 광고는 Google의 AdMob 서비스가 제공합니다.

Google Mobile Ads SDK는 광고, 분석 및 사기 방지 목적으로 다음 정보를 자동으로 수집·공유할 수 있습니다.

  • IP 주소와 이를 통해 추정될 수 있는 대략적인 위치
  • 앱 실행, 탭, 광고 노출·클릭 및 동영상 조회 등 앱 상호작용 정보
  • 앱·SDK의 실행 시간, 중단, 에너지 사용량 등 진단 및 성능 정보
  • Android 광고 ID, 앱 세트 ID 및 해당되는 경우 기기에서 로그인한 계정과 관련된 기타 식별자

이 정보는 광고 게재, 광고 성과 측정, 분석 및 부정 클릭 방지 등의 목적으로 처리되며 TLS로 전송 중 암호화됩니다. 처리 내용과 이용자의 선택권은 Google의 정책 및 공식 데이터 공개 안내에서 확인할 수 있습니다.

  • Google Mobile Ads SDK 데이터 공개 안내
  • Google 개인정보처리방침
  • Google 파트너 사이트·앱에서의 데이터 사용

광고가 접근하지 않는 정보: 광고 구성요소는 앱이 저장한 제품명, 구매처, 주문 정보, 영수증 이미지와 OCR 결과, 검수 상태와 메모, 사용자가 연결한 사진·영상, 녹음 파일, 생성된 PDF에 접근하지 않습니다. 이 정보는 광고 요청에 포함되지 않습니다.

이용자의 선택: Android 설정 > 개인정보 보호 > 광고에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 유럽경제지역, 영국 등 사전 동의가 필요한 지역에서는 앱 실행 시 동의 화면이 먼저 표시되며, 동의하지 않으면 맞춤 광고가 제공되지 않습니다. 해당 지역에서는 앱의 설정 > 광고 동의 설정에서 선택을 다시 변경할 수 있습니다.

사용자가 Android 공유 기능이나 시스템 파일 저장 화면을 이용해 PDF 또는 증빙을 다른 앱이나 위치로 직접 보내는 경우, 그 이후의 처리는 사용자가 선택한 앱 또는 저장 서비스의 정책에 따릅니다. 받자마자는 사용자의 명시적인 선택 없이 해당 파일을 전송하지 않습니다.

3-2. 온디바이스 OCR(Google ML Kit)

받자마자는 Google ML Kit의 기기 내 한국어 문자 인식 기능을 사용합니다. OCR 대상 이미지와 인식된 문자 자체는 Google 또는 원격 OCR 서버로 전송되지 않으며 기기 안에서 처리됩니다.

Google의 ML Kit Android 데이터 공개 안내에 따르면, ML Kit SDK는 모든 기능에서 진단 및 사용 분석을 목적으로 다음 메타데이터를 수집합니다.

  • 제조사, 모델, Android 버전·빌드 및 사용 가능한 ML 하드웨어 가속기 등 기기 정보
  • 패키지명과 앱 버전 등 앱 정보
  • 사용자나 실제 기기를 고유하게 식별하기 위한 것이 아닌 설치별 식별자
  • 지연 시간 등 성능 지표와 이미지 형식·해상도 등 API 구성
  • 기능 입력·출력 크기와 기능 버전
  • 초기화, 모델 다운로드, 문자 감지, 리소스 해제 등의 이벤트 유형 및 관련 오류 코드

이 메타데이터는 HTTPS로 전송 중 암호화되며, Google의 공개 안내에 따르면 제3자에게 공유되지 않습니다. 이는 위 3-1항의 AdMob 데이터 수집·공유와 구분됩니다.

  • Google ML Kit Android 데이터 공개 안내
  • Google 개인정보처리방침

4. 앱 권한

권한 또는 기능 사용 목적 사용자 선택
INTERNET, ACCESS_NETWORK_STATE 배너 광고 통신 및 ML Kit의 진단·사용 분석 메타데이터 전송 별도 권한창은 없습니다. 앱의 검수 기록, 증빙, OCR 대상 이미지와 인식된 문자는 이 통신으로 전송되지 않습니다.
AD_ID 배너 광고 게재와 부정 클릭 방지를 위한 광고 식별자 사용 Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
RECORD_AUDIO 사용자가 직접 시작한 음성 증빙 녹음 녹음 기능을 사용할 때 요청하며, 거부해도 음성 녹음을 제외한 기능은 사용할 수 있습니다.
POST_NOTIFICATIONS 반품 마감 D-7, D-3, D-1 알림 표시 알림을 사용할 때 요청하며, 거부해도 검수와 기록 기능은 사용할 수 있습니다.
VIBRATE 허용된 알림의 진동 별도 권한창은 없으며 기기와 알림 채널 설정에 따릅니다.
Photo Picker / 시스템 파일 선택기 사용자가 고른 사진·영상·문서만 열기 사용자가 항목을 직접 선택합니다. 앱은 사진 보관함이나 저장공간 전체 접근 권한을 요구하지 않습니다.

권한은 Android 설정에서 언제든 변경할 수 있습니다. 권한을 철회하면 관련 기능이 제한될 수 있지만, 앱이 이미 개발자 서버로 정보를 보낸 상태가 되는 것은 아닙니다. 받자마자에는 개발자 서버로의 전송 기능이 없으며, 네트워크 통신은 배너 광고와 위 3-2항의 ML Kit 진단·사용 분석 메타데이터 처리에 사용됩니다.

5. 저장 위치와 보유 기간

  • 제품 기록, OCR 결과, 검수 상태, 알림 정보와 음성 파일은 앱의 기기 내부 저장공간에 보관됩니다.
  • 선택한 사진·영상은 원본을 제공하는 사진 또는 파일 앱에 남으며, 받자마자는 선택된 항목에 대한 URI 접근 정보를 로컬에 보관할 수 있습니다.
  • 사용자가 시스템 저장 화면에서 내보낸 PDF는 사용자가 선택한 외부 위치에 보관됩니다.
  • 앱은 Android 클라우드 백업을 사용하지 않습니다.

내부 기록은 사용자가 삭제할 때까지 기기에 남습니다. 원본 사진·영상이 이동 또는 삭제되거나 URI 접근 권한이 사라지면 앱에서 해당 증빙을 열지 못할 수 있습니다.

6. 정보 삭제 방법

사용자는 다음 방법으로 정보를 삭제할 수 있습니다.

  • 앱 안에서 제품 기록 또는 연결된 증빙 삭제
  • Android의 설정 > 앱 > 받자마자 > 저장공간 > 데이터 삭제 실행
  • 앱 제거

외부 위치에 내보낸 PDF와 원본 사진·영상은 앱 데이터와 별개입니다. 해당 파일은 사용자가 파일 앱 또는 사진 앱에서 직접 삭제해야 합니다.

7. 계정과 계정 삭제

받자마자는 사용자 계정을 만들거나 로그인을 요구하지 않습니다. 따라서 서버 계정이나 개발자에게 요청할 계정 삭제 절차가 없습니다. 모든 앱 내부 데이터는 위의 로컬 삭제 방법으로 사용자가 직접 관리할 수 있습니다.

8. 제3자 구성요소와 시스템 기능

받자마자는 이미지의 문자를 기기 안에서 인식하기 위한 Google ML Kit 온디바이스 OCR 라이브러리를 포함합니다. OCR 대상 이미지와 인식 결과는 원격 OCR 서버로 전송되지 않지만, ML Kit가 처리하는 진단·사용 분석 메타데이터는 위 3-2항과 같습니다.

또한 배너 광고를 위해 Google Mobile Ads SDK(AdMob)와 동의 수집을 위한 User Messaging Platform SDK를 포함합니다. 이 광고 구성요소의 데이터 수집·공유와 이용자의 선택권은 위 3-1항에서 설명하며, ML Kit의 데이터 처리와 구분됩니다. 각 구성요소에는 Google의 개인정보처리방침이 함께 적용됩니다.

Google Play를 통한 앱 설치·업데이트, Android 운영체제의 시스템 선택기, 사용자가 선택한 파일·사진·공유 앱은 각각 해당 서비스 제공자의 기능입니다. 사용자가 이러한 외부 서비스나 앱을 선택해 이용하는 경우에는 해당 제공자의 개인정보처리방침이 적용될 수 있습니다.

9. 아동의 개인정보

받자마자는 어린이를 대상으로 설계된 앱이 아니며, 계정이나 서버를 통해 아동의 개인정보를 수집하지 않습니다. 광고 요청 시에도 아동 대상 처리로 설정하지 않으며, 광고 콘텐츠 등급은 전체 이용가 수준으로 제한합니다. 보호자는 아동이 기기에 민감한 영수증, 사진, 영상 또는 음성을 저장하지 않도록 기기 사용을 지도할 수 있습니다.

10. 데이터 보호와 사용자의 관리

앱 내부 데이터는 Android가 앱별로 분리한 저장공간에 보관되며 Android 클라우드 백업은 비활성화되어 있습니다. 다만 기기 자체의 잠금 해제, 루팅, 악성 소프트웨어, 사용자가 선택한 공유 대상 또는 외부 저장 위치까지 받자마자가 통제할 수는 없습니다.

영수증, 주문번호, 사진, 영상, 음성에는 민감한 정보가 포함될 수 있으므로 기기 화면 잠금을 사용하고, PDF와 증빙을 공유할 때 수신자와 포함 내용을 직접 확인하는 것을 권장합니다.

11. 방침 변경

앱 기능, 데이터 처리 방식 또는 관련 요구사항이 바뀌면 이 방침을 수정할 수 있습니다. 중요한 변경이 있는 경우 앱 또는 배포 페이지를 통해 새 시행일과 함께 알립니다. 변경된 방침은 표시된 시행일부터 적용됩니다.
